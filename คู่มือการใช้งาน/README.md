# คู่มือการใช้งานระบบแจ้งซ่อมและบริการด้านไอที (ฉบับกระชับ)
**งานเทคโนโลยีสารสนเทศ วิทยาลัยชุมชนสมุทรสาคร (SMKCC)**

---

## 4 ขั้นตอนง่ายๆ ในการแจ้งซ่อมไอทีผ่าน LINE

### 1. เปิดหน้าแจ้งซ่อมผ่าน LINE
* **บนมือถือ (Smartphone):** กดปุ่ม **"แจ้งซ่อมไอที"** ที่แถบ Rich Menu ด้านล่างห้องแชท
* **บนคอมพิวเตอร์ (LINE PC):** พิมพ์หรือคลิกคำว่า **"แจ้งซ่อม"** ในแชท
* *ระบบดึงชื่อโปรไฟล์และ LINE ID อัตโนมัติ (ไม่ต้องลงทะเบียนใหม่)*

---

### 2. กรอกข้อมูลแจ้งปัญหา (1 นาที)
1. **ข้อมูลผู้แจ้ง:** ชื่อ-สกุล & เบอร์โทรศัพท์
2. **สถานที่:** ระบุอาคาร และห้อง
3. **หมวดหมู่ปัญหา:** เน็ตหลุด, คอมพิวเตอร์, Zoom / เสียง ฯลฯ
4. **แนบรูปภาพ:** ถ่ายภาพหน้าจอหรือจุดที่เสีย
* *สามารถเลือกระดับความเร่งด่วน เช่น เร่งด่วนกระทบการเรียนการสอน*

---

### 3. รับการแจ้งเตือนสถานะผ่าน LINE
ระบบจะแจ้งเตือนความคืบหน้าตรงเข้า LINE ทันทีเมื่อเจ้าหน้าที่อัปเดตสถานะ:
* 🟡 **รับเรื่องแล้ว (New)** : ส่งถึงเจ้าหน้าที่เรียบร้อย
* 🔵 **กำลังดำเนินการ (In Progress)** : เจ้าหน้าที่กำลังแก้ไข/ลงพื้นที่
* 🟠 **อยู่ระหว่างดำเนินการ (Pending)** : อยู่ระหว่างรอชิ้นส่วน หรือรอข้อมูลเพิ่มเติม
* 🟢 **เสร็จสิ้น (Complete)** : ดำเนินการแก้ไขเรียบร้อยแล้ว
* *ติดตามสถานะงานได้ตลอด 24 ชม.*

---

### 4. ประเมินความพึงพอใจการบริการ
* เมื่อช่างปิดงาน จะมีลิงก์ส่งมาใน LINE เพื่อให้ผู้ใช้ร่วมประเมิน
* ให้คะแนนการให้บริการ (1 ถึง 5 ดาว) ⭐⭐⭐⭐⭐
* สามารถพิมพ์ข้อเสนอแนะเพิ่มเติมเพื่อพัฒนาการบริการ
